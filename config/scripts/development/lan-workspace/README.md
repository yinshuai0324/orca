# Orca 局域网开发原型

从源码启动 Orca 时，在 Mac 的日常开发终端运行 `pnpm dev`。客户端用启动 Orca 的终端环境运行本机开发服务。

1. 打开 Orca 的 **设置 → SSH 远程主机**，选择已有的主机，或用原有的添加操作登记主机。
2. 在主机的 **⋯ → 挂载本机项目** 里选择 Mac 项目目录，点击 **连接并挂载**。登录与指纹确认走 Orca 的 SSH 流程，挂载后会在项目目录打开远端终端。
3. 在终端里运行远端已有的命令或 AI CLI。远端 Mac 第一次保存项目文件后，Orca 会启动或复用开发机上的服务，等预览地址可访问后打开浏览器。连接前可展开 **本机预览设置**，修改默认的 `npm run dev` 和 `http://127.0.0.1:5173/`。任一字段留空可关闭自动预览。也可以用 **本机启动并预览** 提前打开页面。

**仅打开终端** 可以直接连接到远端主目录。共享 Mac 项目时使用 **连接并挂载**。

远端 Mac 的 SSH 服务须允许反向转发。Orca 在开发机启动临时 SMB 服务并在同一条 SSH 连接上转发，使用远端自带的 `mount_smbfs`。远端挂载和卸载均以 SSH 登录用户执行。两端的 SMB 端口只监听各自的回环地址，共享密码由 Orca 按连接生成。本机使用 `fileshare` 的底层 [go-filesystems/smb](https://github.com/go-filesystems/smb) 库。首次使用时会下载并校验构建工具，编译结果缓存在项目的 `node_modules/.cache/orca-lan-smb` 下。

远端 Linux 使用 SSHFS 的 passive 模式，需要 SSHFS/FUSE（SSH 会话可见 `/dev/fuse`）、`fusermount3` 或 `fusermount`。连接后使用 **本机启动并预览** 打开页面。

弹窗管理一个项目及对应的 SSH 终端，关闭弹窗时卸载并释放项目的转发。已有的 SSH 会话可复用，挂载专用的连接则随项目关闭。项目目录和预览设置按主机保存。文件服务只暴露所选目录，跳过环境文件、Git 元数据、`node_modules`、符号链接和硬链接。
