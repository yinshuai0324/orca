# Orca 局域网开发原型

从源码启动 Orca 时，在 Mac 的日常开发终端运行 `pnpm dev`。客户端用启动 Orca 的终端环境运行本机开发服务。

1. 打开 Orca 的 **设置 → SSH 主机 → 添加主机**，将主机类型选为 **SSH（共享本机目录）**。填写 SSH 信息，选择本机项目目录并保存。
2. 在主机列表点击该主机的 **连接**。登录与指纹确认走 Orca 的 SSH 流程，挂载后会在共享目录打开远端终端。要更换目录，卸载后编辑该主机。
3. 在终端里运行远端已有的命令或 AI CLI。远端 Mac 第一次保存项目文件后，Orca 会启动或复用开发机上的服务，等预览地址可访问后打开浏览器。添加或编辑主机时可展开 **本机预览设置**，修改默认的 `npm run dev` 和 `http://127.0.0.1:5173/`。任一字段留空可关闭自动预览。也可以用 **本机启动并预览** 提前打开页面。

远端 Mac 的 SSH 服务须允许反向转发。Orca 在开发机启动临时 SMB 服务并在同一条 SSH 连接上转发，使用远端自带的 `mount_smbfs`。远端挂载和卸载均以 SSH 登录用户执行。两端的 SMB 端口只监听各自的回环地址，共享密码由 Orca 按连接生成。本机使用 `fileshare` 的底层 [go-filesystems/smb](https://github.com/go-filesystems/smb) 库。首次使用时会下载并校验构建工具，编译结果缓存在项目的 `node_modules/.cache/orca-lan-smb` 下。

远端 Linux 使用 SSHFS 的 passive 模式，需要 SSHFS/FUSE（SSH 会话可见 `/dev/fuse`）、`fusermount3` 或 `fusermount`。连接后使用 **本机启动并预览** 打开页面。

弹窗管理一个项目及对应的 SSH 终端，关闭弹窗时卸载并释放项目的转发。项目目录和预览设置按主机保存。文件服务仅共享开发机上的所选目录，跳过环境文件、Git 元数据、`node_modules`、符号链接和硬链接。远端终端保留 SSH 账号对远端自身文件和 CLI 配置的权限。
